# Tavola, zona, nazionale

Il campo `livello` del profilo adatta le skill al ruolo di chi le usa.

| Funzione | Tavola | Zona (beta) | Nazionale (beta) |
| --- | --- | --- | --- |
| Profilo, direttivo, firme | ✅ | ✅ (Comitato di Zona) | ✅ (Comitato Nazionale) |
| Anno sociale | dalla domenica dopo l'AGM (di solito il primo sabato di giugno), formato `AAAA-AAAA` | uguale | uguale |
| Archivio condiviso (`rt-archivio`) | ✅ `Documenti legali/` + `Anni sociali/AAAA-AAAA/` (Eventi, Direttivo, Tesoreria, Comunicazione) | ✅ stessa struttura, cartella della zona | ✅ stessa struttura, cartella del nazionale |
| Bollettino: destinatari "e p.c." di default | Nazionale + Comitato di Zona + Presidenti delle tavole della zona | Nazionale + Presidenti delle tavole della zona | Presidenti di Zona + Presidenti di Tavola |
| Eventi, pack, spese | ✅ | ✅ (eventi di zona) | ✅ (eventi nazionali) |
| App RTIT: Planner e prossimi eventi | unità = tavola, area = zona | unità = zona | eventi nazionali (`--nazionali`) |
| Adempimenti (`rt-presidente`) | ✅ dal Manuale del Presidente | ✅ `rt-presidente`, `references/zona.md`: CZ, deleghe, quote di zona, report sulle tavole | parziale: deleghe, candidature e passaggio di consegne; manuale del Comitato Nazionale da scrivere |
| Direttivo e verbali (`rt-direttivo`) | ✅ | ✅ `rt-direttivo` (Comitato di Zona e CZ) | ✅ `rt-direttivo` (Comitato Nazionale) |
| Statistiche e report sulle tavole (`rt-app-rtit`) | eventi della tavola per anno sociale | ✅ statistiche delle tavole della zona | ✅ statistiche nazionali e per zona |
| Crescita (`rt-crescita`) | ✅ | ✅ (workshop per le tavole: RTIT University §16) | ✅ |

## Cosa manca (contributi benvenuti)

- Un "manuale del Presidente di Zona" e uno del Comitato Nazionale, da distillare come è stato fatto per il Manuale del buon Presidente.
- Report di zona completo: oggi gli eventi e le statistiche vengono dall'App RTIT (`rt-app-rtit`); mancano stato delle quote e adempimenti delle tavole.
- Template di bollettino per zona e nazionale: oggi si usa quello generico con l'intestazione del profilo.
